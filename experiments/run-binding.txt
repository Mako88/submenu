Sentinel for .github/workflows/plexus-binding.yml.

Editing this file starts a 20-seed run of the binding sweeps. It exists so that
writing a *result* into experiments/sweeps/binding-*.txt does not re-run the
matrix that produced it, which the previous path filter did every time -- about
eleven minutes of CI per recorded result.

Record what each run was for, so the artifacts can be matched to a question.

run 1 -- sweeps 015/016/017/018, ten conditions per seed.
  binding on/off measured offline (linear, MLP), and end to end across delta,
  RLS, catch-up, two decay rates and a bind-then-stop schedule.
  Results in experiments/sweeps/binding-015 .. -018.

run 2 -- adds sweep 019: linear decodability every 25 episodes across training,
  binding on vs off, to separate "binding is slow" from "the readout is slow".
  Prediction recorded in experiments/sweeps/binding-019-trajectory.txt.

run 3 -- adds sweep 020: lateral inhibition (Vogels-Sprekeler anti-Hebbian rule
  on the existing inhibitory synapses), plus correlation and effective-rank
  columns on every condition. Tests the premise behind the whole
  decorrelation direction, which one seed says is backwards.
  Prediction in experiments/sweeps/binding-020-decorrelation.txt.

run 4 -- sweep 021: lateral inhibition end to end. Adds lat-on, latbind-on,
  latbind-rls and latbind-catchup; drops sweep 018's three schedule conditions
  and sweep 019's trajectory probe, whose questions are answered and written
  up. `latbind-on` against `rls-on` is the one that matters -- a local rule
  under the shipped delta readout against RLS's pooled correlation matrix.
  Prediction in experiments/sweeps/binding-021-lateral-end-to-end.txt, which
  predicts it is null and names closing the direction as the consequence.

run 5 -- sweep 026: the architecture's headline claim, measured on a mechanism
  that works. AUDIT asked for the three-factor rule under modulator lag, but
  that rule is worth -0.003 at lag 0, so measuring whether a null degrades tests
  nothing -- the same shape as sweep 022's preset-frozen, a condition whose
  outcome is guaranteed by how it is built. Replaced rather than run as
  specified.

  Binding is the right vehicle: it pays +0.074 at p = 0.0000, and it reads the
  modulator only for its presence, scoring a 50ms window on the neuron's own
  activity at the instant it lands. A late modulator scores a decayed window, so
  the mechanism is latency-sensitive by construction.

  Seven conditions: off and on at lag 0, off at lag 150 (the sanity check that
  sweep 013's drain-tail confound is fixed), on at lags 25/50/150, and on at lag
  150 with tau_act_fast raised to 250 -- which asks whether latency tolerance is
  a property or a parameter. drain_steps pinned at 200 everywhere.

  Prediction in experiments/sweeps/binding-026-latency-tolerance.txt, derived
  arithmetically from exp(-lag/tau) rather than guessed, and naming
  no-decay-at-all as the outcome that would mean the instrument is broken.
