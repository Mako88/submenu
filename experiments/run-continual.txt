Sentinel for .github/workflows/plexus-continual.yml.

Editing this file starts a 20-seed run. It exists so that writing a *result*
into experiments/sweeps/ does not re-run the matrix that produced it -- GitHub
path filters cannot tell a file being added from one being edited, so the
trigger has to live where results are never written.
